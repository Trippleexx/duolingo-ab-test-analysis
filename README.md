# 📚 Анализ A/B-теста Duolingo: Оценка новой техники запоминания

---

## 📌 Бизнес-кейс

Одна из ключевых задач для платформ по изучению языков — повышение способности пользователей удерживать в памяти выученный материал. Часто используемый подход заключается во внедрении новых техник запоминания и проверке их эффективности с помощью контролируемых A/B-экспериментов.

В этом проекте я анализирую A/B-эксперимент на основе набора данных Duolingo, чтобы оценить, улучшает ли новая техника запоминания результаты обучения пользователей.

Цель — не только определить, работает ли новый подход лучше существующего, но и оценить, является ли наблюдаемое улучшение статистически значимым и достаточно большим, чтобы оправдать продуктовое решение.

---

## 🎯 Бизнес-цель

Оценить, следует ли рекомендовать новую технику запоминания к внедрению на основе статистических данных.

Основные вопросы:

Улучшает ли новая версия вероятность запоминания пользователями материала?
Является ли наблюдаемое различие статистически значимым?
Имеет ли эффект практическую значимость?
Улучшает ли новая версия удержание пользователей?
Какую рекомендацию следует дать продуктовой команде?

---

## 📊 Данные

В проекте используется образовательный набор данных, содержащий наблюдения на уровне пользователей из смоделированного A/B-эксперимента.

Набор данных включает информацию о:

группе эксперимента (A / B);
вероятности запоминания (p_recall_ab);
удержании через 7 дней (retention_7d);
дополнительных переменных, связанных с экспериментом.

## 🔍 Этапы работы над проектом

### 1. Исследование данных

Анализ начинается с первичного осмотра набора данных.

Выполненные задачи:

загрузка набора данных;
проверка размерности;
просмотр названий столбцов и типов данных;
обнаружение пропущенных значений;
выбор целевой метрики (p_recall_ab);
разделение наблюдений на экспериментальные группы;
проверка сбалансированности групп.
### 2. Описательные статистики

Описательные статистики были рассчитаны отдельно для каждой экспериментальной группы с использованием NumPy.

Рассчитанные метрики:

среднее арифметическое;
медиана;
стандартное отклонение;
минимальное и максимальное значения;
25-й перцентиль;
75-й перцентиль.
Дополнительно:

абсолютная разница между средними группами;
относительная процентная разница.
Этот этап даёт первоначальное понимание эксперимента до проведения формального статистического тестирования.

### 3. Статистический анализ (A/B-тест)

Чтобы оценить, могли ли наблюдаемые различия возникнуть случайно, был проведён двухвыборочный t-тест для независимых выборок.

Были выполнены следующие шаги:

формулировка нулевой и альтернативной гипотез;
расчёт p-значения;
сравнение с уровнем значимости (α = 0,05);
интерпретация статистической значимости.
Для оценки практической значимости в проекте также оцениваются:

абсолютный размер эффекта;
относительный размер эффекта;
качественная интерпретация эффекта:

Небольшой (<5%)
Умеренный (5–15%)
Большой (>15%)
### 4. Визуализация данных

Чтобы лучше понять результаты эксперимента, были созданы несколько визуализаций.

В том числе:

гистограммы распределений;
сравнение распределений по группам;
индикаторы средних значений.
Визуализации помогают выявить различия, которые могут быть не сразу заметны только по числовым статистикам.

### 5. Анализ конверсии

Помимо вероятности запоминания, в качестве дополнительной продуктовой метрики было оценено удержание пользователей.

Конверсия была определена как:

доля наблюдений, где retention_7d = 1.
Анализ включает:

расчёт конверсии для групп A и B;
построение таблицы сопряжённости;
критерий хи-квадрат для сравнения долей;
интерпретацию p-значения;
статистический вывод.

## 💼 Продуктовая рекомендация

На основе статистического анализа в проекте формулируется рекомендация для продуктовой команды.

Логика принятия решения:

статистически значимое улучшение → рекомендовать внедрение;
статистически значимое ухудшение → рекомендовать доработку новой версии;
отсутствие статистически значимых различий → рекомендовать сбор дополнительных данных перед принятием продуктового решения.
